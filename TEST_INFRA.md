# Test Infrastructure: 「设计 Skill 展示站」(ai-design-skills-bench-vercel)

## Overview

The test infrastructure provides an opaque-box, requirement-driven, zero-dependency testing framework using the standard Node.js test runner (`node:test` and `node:assert/strict`).

It enforces user requirements **R1 through R5**, Acceptance Criteria, and Feature Specifications **F01 through F22** across four rigorous test tiers without reliance on external npm packages.

---

## Environment & Prerequisites

- **Runtime**: Node.js v18.0.0+ (Tested on Node.js v24.16.0)
- **Module System**: ECMAScript Modules (`.mjs`)
- **Dependencies**: 0 external dependencies (Standard library only: `node:test`, `node:assert`, `node:fs`, `node:path`, `node:url`)
- **Execution Target**: Output artifacts generated by `node site/build.mjs` in `site/dist/`

---

## Directory Layout

```
tests/
├── e2e.test.mjs                     # Master test runner entrypoint
├── tier1-feature-coverage.test.mjs   # Tier 1: Core feature coverage (F01-F22)
├── tier2-boundary-cases.test.mjs    # Tier 2: Boundary, error handling & stress
├── tier3-cross-combinations.test.mjs# Tier 3: Pairwise cross-feature interactions
├── tier4-workload-scenarios.test.mjs# Tier 4: Real-world end-to-end user journeys
└── helpers/
    ├── html-parser.mjs              # Zero-dependency HTML & CSS inspection utilities
    └── client-sim.mjs               # Pure JS client state & URL sync simulator
```

## Execution Commands

### 1. Build and Run Full Test Suite
```bash
node site/build.mjs
node --test tests/e2e.test.mjs
```
*Alternative direct execution:*
```bash
node tests/e2e.test.mjs
```

### 2. Run Specific Tiers
```bash
# Tier 1 only: Core feature coverage
node --test tests/tier1-feature-coverage.test.mjs

# Tier 2 only: Boundary & corner cases
node --test tests/tier2-boundary-cases.test.mjs

# Tier 3 only: Pairwise combinations
node --test tests/tier3-cross-combinations.test.mjs

# Tier 4 only: Real-world workload scenarios
node --test tests/tier4-workload-scenarios.test.mjs
```

### 3. Generate TAP / Formatted Reports
```bash
node --test --test-reporter=tap tests/e2e.test.mjs
node --test --test-reporter=spec tests/e2e.test.mjs
```

## 4-Tier Test Architecture

| Tier | Focus | Scope & Categories | Target Count |
|---|---|---|---|
| **Tier 1** | **Feature Coverage** | Static build integrity, Homepage decision headline (F01), 9+1 nomenclature (F05), Duration cumulative note (F06), V3 context (F07), Task filter (F02), Card information hierarchy (F03), 3-tier provenance (F04), 00-bare read_skill fix (F08), Token separation (F09), taste-skill interruption flag (F10), Multi-candidate comparison (F11, F12), URL state sync (F13), Return link memory (F14), Detail dimensions (F15), Accordions (F16), Standalone preview (F17), Editor text removal (F18), Mobile layout (F19), Visual tokens (F21), Accessibility (F22). | 35+ tests |
| **Tier 2** | **Boundary & Corner Cases** | URL query edge cases (>3 candidates cap, empty/malformed params, unknown task/edition fallbacks, XSS neutralization), content edges (empty review placeholders, multi-task matching, 00-bare baseline flag, null exit codes), responsive boundaries (table wrapping, fluid images, touch sizing, word-break). | 17+ tests |
| **Tier 3** | **Cross-Feature Combinations** | Pairwise interactions: Task Filter + Edition Switcher; Comparison Mode + URL Persistence; Task Filter + Comparison Selection; Detail Navigation + State Memory Return Link; Responsive Breakpoint + In-Place Mobile Switcher; Accordion Toggle + Keyboard Focus. | 10+ tests |
| **Tier 4** | **Real-World Workload Scenarios** | 4 complete end-to-end user journeys: 1. Portfolio Designer Workflow; 2. Technical Benchmark Auditor Workflow; 3. Mobile Evaluator (390px Viewport) Workflow; 4. Direct Shareable Deep-Link Workflow. | 4+ scenarios |
