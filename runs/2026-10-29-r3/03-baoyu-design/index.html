关于我

名字取自 chase。追工具、追模型，也追把想法做成能跑的东西。

我是 Chasen，20 岁，计算机科学大四，在广州。本职是 AI 开发工程师，一边实习一边做 Agent 工具：给 Pi 写桌面客户端，也把每天重复的活儿拆成一个个 Agent Skills。

每天在 Pi、Claude Code 和 Codex 里泡着。看得多了，在意的不只是「能不能跑」，还有「为什么是这样设计」。所以现在认真在考虑往 AI 产品经理方向走——开发是我的底子，产品是正在补的课。

在 X 上写 Pi 和 Agent 工具的实测、新模型上手、大四找工作的进度，以及从开发转产品这条路的真实记录。
