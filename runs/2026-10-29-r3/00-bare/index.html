Chasen Liao Guangzhou · CS 2026

我是 Chasen，20 岁，计算机科学大四，人在广州。现在的本职是 AI 开发工程师，一边实习，一边做 AI Agent 工具。

目前投入最多的是 pi-agent-desktop：一个给 Pi 编程智能体用的 Electron 桌面客户端。原生窗口、会话分叉、SSE 流式对话、模型中途切换、内置文件浏览器——都是我自己每天会碰的东西，就顺手放进同一个窗口里。

另一条线是 Agent Skills。把重复的工作流写成 Agent 能直接执行的技能：按 JD 改简历、把任务并行拆开、复盘我在 X 上发过的内容。能交给 Agent 的，就不手动做第二遍。

“能复用的，就不手动做第二遍。”—— 我给自己定的规矩

我还在 X 上记录 Pi / Agent 工具实测、新模型上手、大四找工作的进展，以及从开发往产品走的这段探索。最近在认真考虑转 AI 产品经理：不是不写代码，而是想更早参与决定「做什么」。

Chasen 取自 chase。提醒自己别停在原地。
