# Chasen 个人落地页 — 设计与验证记录

交付文件：`index.html`（项目根目录，单文件）

## 设计方向

**北极星**：像一份还在写的工程笔记，而不是一张排版好的简历。名字是「追」，作品是留下的刻度。

- **首屏主角 / 主动作**：满版宽度的 CHASEN 字标；主动作「去 X 找我」，次动作「看作品」下沉为文字按钮。
- **首屏骨架**：通栏上下堆叠（meta → 巨型字标 → 定位句 + CTA），没有用左右分栏的默认落地页结构。
- **生成引擎**：编辑型工程手稿。纸张底色、硬边细线、等宽字数据、红蓝笔式的单一强调色；滚动推进一段“chase → chasen”的字标叙事。
- **调性**：能量偏高、完成度偏精致、密度疏、分量重、严肃度偏活泼。依据：20 岁、Agent 工具作者、X 上写实测，内容本身不庄重。
- **色彩**：纸色 `#F3EFE6` / 墨色 `#121317` / 钴蓝 `#1F3BFF`（取自 Q 版角色卡的青蓝耳机，也作为“信号”色）；暗底上的强调用 `#93A2FF`。没有紫蓝发光、没有渐变文字、没有粒子。
- **字体**：Archivo 900（字标与项目名）、Noto Sans SC（中文正文）、JetBrains Mono（数据、标签、链接）。中文正文 17px / 1.8。
- **图标**：不用图标库，用字符 `↗` `↓`、编号与细线；避免每个标题配图标。
- **控件语法**：2px 直角、1px 描边、按下 0.99 缩放；链接用下划线而不是胶囊。
- **记忆点**：名字章里，首屏以下的钴蓝整屏把 `CHASE` 拉开，滚动时字母收拢、多出来的 `N` 落位，变成 `CHASEN`；配文 “chase + n = chasen”。

## 页面结构

1. 固定顶栏 + 左侧 1px 进度轨（≥1280px 显示）
2. 首屏：meta / CHASEN / 定位句 + 两个 CTA + 「链接待填」说明
3. 钴蓝跑马灯：项目与能力关键词
4. 关于：自我介绍、事实表、Q 版设定卡（multiply 混入纸面）
5. 名字章：钴蓝整屏，pin + scrub 的 chase → chasen
6. 精选作品：旗舰对象（pi-agent-desktop）+ 4 条账本行
7. 日常：墨色三栏工作台 + 正在折腾
8. 联系：墨色大区块、岗位标签、5 个外链位、头像名片
9. 页脚

## 链接处理

- 个人站 / 博客 / GitHub / X / Email 全部 `href="#"`，旁边标「链接待填」；点击给一条 toast，说明“链接待填”，不跳走。
- 首屏「去 X 找我」同样留空；「看作品」是页内锚点，不依赖外部 URL。
- 5 个项目仓库用用户给的真实 GitHub 地址，新标签打开。
- Email 只显示 “Email” 标签，没有邮箱地址。

## 动效

1. **首屏入场**：字母从遮罩里升起，meta 与 CTA 随后淡入；只在首次进入播放。
2. **主操作反馈**：按钮按下缩到 0.99，hover 时箭头位移；外链位点击弹 toast。
3. **状态切换**：移动端菜单从顶栏下方落下，背景滚动锁住，Esc 关闭，展开按钮变成 X。
4. **滚动叙事**：名字章 pin 住 135svh，字母 x 位移收拢、N 落下、配文淡入；全部由滚动位置驱动，可倒放。
5. **区块出场**：首屏以下的区块在进入视口时一次性淡入上移（`once`），不重复播放；作品列表的四行按阅读方向依次错开 70ms，而不是整块一起出现。
6. **进度轨**：左侧 1px 钴蓝线随页面滚动填充。
7. **跑马灯**：关键词横向循环，hover 暂停。
8. **减少动态效果**：关闭 pin、入场与循环动画，所有内容直接可读。

## 验证记录

- 视口：1440×900、390×844、768×1024、320×640、1920×1080、720×450（约 200% 缩放）。
- 无横向溢出（跑马灯与 skip link 除外）；无控制台错误；两张本地图片均能加载（头像为 lazy，滚到联系区后 naturalWidth=400）。
- Pin 实测：名字章在 1215px 滚动距离内保持 `top≈0`，字母从散开到收拢，配文从透明到 1；减少动态效果下无 pin，字标直接是收拢状态。
- 移动菜单：`aria-expanded` 正确，打开时 `body overflow:hidden`，点链接后关闭并滚到对应区块，Esc 可关。
- 外链位点击不改变 scrollY，toast 文案正确。
- 中文断行检查：390/768/1440 下无段末孤字；320 下的两处已用 `text-wrap:pretty` 修掉。
- 设计工具默认做法检查：只剩「单文件 44 KiB」一条，属于用户明确要求“只输出一个 index.html”，保留。
