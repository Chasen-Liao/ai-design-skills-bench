我是 Chasen Liao，20 岁，在广州读计算机科学，今年大四。

日常是一边实习，一边做自己的 Agent 工具：给 Pi 写了一个桌面客户端，也攒了一套自用的 Agent Skills。每天在用 Pi、Claude Code 和 Codex，大部分代码、任务和资料都在这些工具里过一遍。

在 X 上写这些工具的实测、新模型上手、大四找工作，也写最近从开发往产品挪的尝试。写出来的基本都是我自己用过、踩过的东西。

以后要成为什么样的人，我还没完全想清楚；但想做什么样的东西，比较确定——能被人每天打开，用完还会想再打开一次的那种。
