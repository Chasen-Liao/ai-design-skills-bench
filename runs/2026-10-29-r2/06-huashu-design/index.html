我 20 岁，在广州读计算机科学，今年大四。现在一边实习，一边做 AI Agent 工具。

主线是 Pi：一个给编程智能体用的桌面客户端，和一堆自己每天要用的 Agent Skills。做这些的理由很直接——现有的不够顺手，就自己改。

每天在用 Pi、Claude Code 和 Codex 写东西，主力是 Python 和 TypeScript / React。也做过 Electron、FastAPI、向量检索这些活。新的模型和工具出来，我通常先上手，再回头补文档。

最近花更多时间想的，不是「还能加什么功能」，而是「这个东西该长什么样、给谁用」。所以除了 AI 开发工程师，我也在认真看 AI 产品经理 的机会。

现在最想搞清楚的是：一个顺手的工具，和一个真的有人用的产品，中间差的是什么。
